01. Tabular Q-Learning

The foundation of environment action-reward loops.

Reinforcement Learning relies heavily on a mathematical frame called a Markov Decision Process (MDP). An agent interacts with an environment by viewing its current State (S), making an Action (A), and receiving a corresponding Reward (R) along with a new updated state.

In tabular Q-Learning, we track knowledge via a lookup framework matrix called a Q-Table. The system records updates by calculating errors via the classic Bellman Equation formulation:

Q(s, a) = Q(s, a) + α * [R + γ * max(Q(s', a')) - Q(s, a)]

Parameter Glossary:

  • α (Alpha): Learning rate. Controls tracking responsiveness.
  • γ (Gamma): Discount factor. Values long-term returns vs immediate payoffs.
  • Exploration (ε-greedy): Promotes discovery of alternate, unmapped paths over pure exploitation.
