02. Deep Q-Networks (DQN)

Scaling RL to infinite state spaces using Deep Learning.

In classic RL, a Q-table works perfectly for small grids. But what happens when your input is a high-resolution camera frame? The state space becomes infinite, making a lookup table impossible to store in memory.

DQN solves this by replacing the Q-table with a Neural Network. Instead of looking up an index, we pass the state (S) as an input vector into a neural network, which outputs the estimated Q-values for all possible actions simultaneously.

To stabilize training and prevent the network from forgetting past experiences, DQN introduces two critical breakthroughs:

1. Experience Replay: Stores transitions (s, a, r, s') in a circular buffer and samples random mini-batches to break temporal correlations.
2. Target Network: Copies weights periodically to a separate frozen network to keep optimization targets \([R + \gamma \max Q_{target}(s', a')]\) stable.
