# RL Space

An educational website introducing reinforcement learning through lessons and browser-based interactive visualizations.

## Repository guide

- `index.html` — site entry page.
- `lessons/` — lesson and assessment pages covering classic reinforcement learning, DQN, policy gradients, and PPO.
- `css/` — site and lesson styles.
- `js/lessons.js` — controls and canvas visualizations for the lessons.
- `js/game/` — the gridworld environment, Q-learning agent, and simulation engine.

## Viewing

Open `index.html` in a browser and navigate to the lessons. The classic RL lesson includes a gridworld simulation. The DQN, policy-gradient, and PPO controls are illustrative browser visualizations; they should not be mistaken for full model-training implementations.

Files are linked through relative paths. Preserve their locations unless references are updated and the site is checked.
